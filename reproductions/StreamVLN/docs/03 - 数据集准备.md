# 数据集准备

## 1. 先区分三类数据

仅复现公开 checkpoint 的 R2R/RxR 评测时，需要前两类数据；只有重新训练或收集 DAgger 时才需要第三类。

| 类型 | 内容 | 评测是否必需 |
| --- | --- | --- |
| 场景资产 | MP3D（R2R/RxR/EnvDrop）或 HM3D（ScaleVLN）网格和导航网格 | 是 |
| VLN-CE episode | 指令、起终点、参考轨迹等 JSON/JSON.GZ | 是 |
| 训练轨迹 | RGB 观察、动作标注、DAgger 和通用多模态数据 | 否 |

MP3D 和 HM3D 都有单独的许可协议。本文不镜像数据，也不提供绕过授权的下载方式。

## 2. 下载 Matterport3D 场景

先在 [Matterport3D 官方页面](https://niessner.github.io/Matterport/) 阅读许可并申请下载权限。得到官方 `download_mp.py` 后，可单独创建 Python 2.7 环境运行旧下载器：

```bash
conda create -n mp3d-download python=2.7 -y
conda activate mp3d-download

python download_mp.py \
  -o /path/to/mp3d_download \
  --task_data habitat
```

只复现 Habitat 导航时下载 `habitat` task data 即可，无需完整原始扫描。下载器会要求确认许可，按页面和脚本提示完成确认，不要在下载尚未完成时中断。

将得到的 Habitat 场景整理到：

```text
data/scene_datasets/mp3d/
├── 17DRP5sb8fy/
│   ├── 17DRP5sb8fy.glb
│   └── 17DRP5sb8fy.navmesh
├── 1LXtFkjw3qL/
└── ...
```

可以复制，也可以用符号链接节省空间：

```bash
cd "$STREAMVLN_ROOT"
mkdir -p data/scene_datasets
ln -s /absolute/path/to/mp3d data/scene_datasets/mp3d
```

链接目标必须是包含各场景 ID 子目录的那一层。

## 3. 下载 VLN-CE episode

官方仓库给出的入口如下：

- [R2R_VLNCE v1-3](https://drive.google.com/file/d/18DCrNcpxESnps1IbXVjXSbGLDzcSOqzD/view)：解压后将 `R2R_VLNCE_v1/` 重命名为 `r2r/`；虽然压缩包内目录沿用旧名称，评测应使用官方链接中的 v1-3 内容。
- [RxR_VLNCE v0](https://drive.google.com/file/d/145xzLjxBaNTbVgBfQ8e9EsBAV8W-SM0t/view)：重命名为 `rxr/`。
- [EnvDrop](https://drive.google.com/file/d/1fo8F4NKgZDH-bPSdVU3cONAkt5EW-tyr/view)：训练使用，放到 `envdrop/`。
- [ScaleVLN 150K 子集](https://huggingface.co/datasets/cywan/StreamVLN-Trajectory-Data/blob/main/ScaleVLN/scalevln_subset_150k.json.gz)：训练使用，放到 `scalevln/`。

R2R 评测所需的最终结构是：

```text
data/
├── datasets/
│   ├── r2r/
│   │   ├── train/
│   │   ├── val_seen/
│   │   │   └── val_seen.json.gz
│   │   └── val_unseen/
│   │       └── val_unseen.json.gz
│   └── rxr/
│       ├── train/
│       ├── val_seen/
│       └── val_unseen/
└── scene_datasets/
    └── mp3d/
        ├── 17DRP5sb8fy/
        └── ...
```

配置文件 `config/vln_r2r.yaml` 默认读取：

```text
data/datasets/r2r/{split}/{split}.json.gz
data/scene_datasets/
```

因此目录名和层级必须完全一致。

## 4. ScaleVLN 所需 HM3D

如果要训练 ScaleVLN 子集，还需从 [Habitat-Matterport 3D Research Dataset](https://github.com/matterport/habitat-matterport-3dresearch) 按许可下载 HM3D 的 `train` split，并放到：

```text
data/scene_datasets/hm3d/
├── 00000-kfPV7w3FaU5/
├── 00001-UVdNNRcVyV1/
└── ...
```

R2R/RxR checkpoint 评测不需要 HM3D。

## 5. 训练轨迹与通用多模态数据（可选）

预收集的 R2R/RxR observation-action 数据来自 [StreamVLN-Trajectory-Data](https://huggingface.co/datasets/cywan/StreamVLN-Trajectory-Data)，解压到 `data/trajectory_data/`。EnvDrop、ScaleVLN 和 DAgger 数据需要按官方脚本采集。

第二阶段 co-training 还会使用：

- [LLaVA-Video-178K](https://huggingface.co/datasets/lmms-lab/LLaVA-Video-178K)
- [ScanNet](https://github.com/ScanNet/ScanNet) 及 ScanQA/SQA3D 标注
- [MMC4-core](https://github.com/allenai/mmc4)

这些数据体积和训练成本都很高；如果目标只是复现表格中的推理指标，不要下载。

## 6. 完整性检查

在 StreamVLN 根目录运行：

```bash
test -f data/datasets/r2r/val_unseen/val_unseen.json.gz \
  && echo "R2R episodes: OK"

find data/scene_datasets/mp3d -mindepth 2 -maxdepth 2 \
  \( -name '*.glb' -o -name '*.navmesh' \) | head

du -sh data/datasets data/scene_datasets/mp3d
```

也可做一次无 GPU 的 JSON 检查：

```bash
python - <<'PY'
import gzip, json

path = "data/datasets/r2r/val_unseen/val_unseen.json.gz"
with gzip.open(path, "rt") as f:
    payload = json.load(f)
episodes = payload.get("episodes", payload)
print("episodes:", len(episodes))
print("first scene:", episodes[0]["scene_id"])
PY
```

如果首个 `scene_id` 指向某个 MP3D 场景，确认对应 `.glb` 和 `.navmesh` 确实存在，再进入评测步骤。
