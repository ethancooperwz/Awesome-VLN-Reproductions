# 实验结果与分析

## 1. 官方 checkpoint 参考结果

以下数据来自论文当前版本和官方仓库发布的 R2R_VLNCE v1-3 checkpoint，均为 `val_unseen`。数值是百分数，NE 的单位是米。

| 数据集 | NE ↓ | OS ↑ | SR ↑ | SPL ↑ | nDTW ↑ |
| --- | ---: | ---: | ---: | ---: | ---: |
| R2R-CE | 4.90 | 63.6 | 56.4 | 50.2 | — |
| RxR-CE | 5.65 | — | 54.4 | 45.4 | 63.7 |

本地 `result.json` 把 OS、SR 和 SPL 写成 0–1 的比例，因此 R2R 的理想聚合结果大致应显示为 `0.636`、`0.564`、`0.502`，而 NE 仍约为 `4.90`。

不应要求本地结果与表格最后一位完全相同，但明显偏离时应先检查代码 commit、数据版本、episode 数和推理参数。论文未为这些结果报告多随机种子均值与标准差，因此小幅差异不能直接归因于某个实现因素。

## 2. 训练数据消融

论文表 III 在 R2R-CE `val_unseen`、关闭 voxel-based spatial pruning 的条件下报告：

| R2R | RxR | DAgger | 通用 VL 数据 | ScaleVLN | NE ↓ | OS ↑ | SR ↑ | SPL ↑ |
| :---: | :---: | :---: | --- | :---: | ---: | ---: | ---: | ---: |
| ✓ | ✓ |  | 无 |  | 5.98 | 51.3 | 45.6 | 42.3 |
| ✓ | ✓ | ✓ | VideoQA |  | 5.47 | 57.8 | 50.8 | 45.7 |
| ✓ | ✓ | ✓ | VideoQA + MMC4 |  | 5.43 | 62.5 | 52.8 | 47.2 |
| ✓ | ✓ | ✓ | VideoQA + MMC4 | ✓ | 4.90 | 63.6 | 56.4 | 50.2 |
| ✓ | ✓ |  | VideoQA + MMC4 | ✓ | 5.73 | 56.4 | 50.2 | 47.1 |
| ✓ |  | ✓ | VideoQA + MMC4 | ✓ | 5.90 | 55.9 | 47.9 | 43.6 |

可以得到三个较稳妥的结论：

- 加入 ScaleVLN 后，SR 从 52.8 提升到 56.4，SPL 从 47.2 提升到 50.2，说明额外场景多样性有助于未见环境泛化。
- 移除 DAgger 后，SR 从 56.4 降到 50.2，表明纠错轨迹对缓解策略自身造成的状态分布偏移很重要。
- 移除 RxR 后，SR 降到 47.9，且 SPL 降幅更大，说明长路径、多样语言监督对 R2R 泛化也有帮助。

这些是不同训练配方之间的对照，不是简单从完整模型中“运行时关闭某个开关”。复现消融需要分别训练对应模型，不能只改评测参数。

## 3. 记忆容量与滑动窗口消融

论文第一阶段模型的消融结果如下：

| Memory context | Window | NE ↓ | OS ↑ | SR ↑ | SPL ↑ |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2 × 196 tokens | 8 | 6.96 | 48.2 | 37.3 | 34.2 |
| 4 × 196 tokens | 8 | 6.62 | 49.1 | 38.9 | 35.4 |
| 8 × 196 tokens | 8 | 6.05 | 53.8 | 45.5 | 41.6 |
| 全部视觉上下文 | 8 | 6.76 | 49.5 | 40.0 | 36.4 |
| 8 × 196 tokens | 4 | 6.31 | 51.1 | 41.4 | 37.5 |
| 8 × 196 tokens | 2 | 6.16 | 52.8 | 43.7 | 40.3 |

记忆并非越多越好：8 组历史帧优于 2 或 4 组，但保留全部视觉上下文反而下降，说明冗长、变化过多的历史可能引入噪声。窗口为 8 也取得了性能与训练样本量/成本之间更好的平衡。

## 4. 空间 token pruning

论文报告的 v1-3 结果中：

| 方法 | R2R NE ↓ | R2R OS ↑ | R2R SR ↑ | R2R SPL ↑ |
| --- | ---: | ---: | ---: | ---: |
| StreamVLN | 4.90 | 63.6 | 56.4 | 50.2 |
| Prune-Mem | 4.73 | 65.5 | 57.4 | 51.1 |
| Prune-All | 4.82 | 65.7 | 56.0 | 48.5 |

只裁剪 memory frames 在 R2R 上略有提升，同时论文称视觉 token 减少约 28%；对所有流式帧和记忆都裁剪可进一步减少 token，但 SPL 有所下降。这里的提升幅度较小，应避免据单次运行过度解读。

## 6. 失败案例分类

可以根据 episode 结果先分四类，再看视频：

| 条件 | 类型 | 优先检查 |
| --- | --- | --- |
| OS=0, SR=0 | 从未到达 | 指令理解、岔路选择、碰撞/卡死 |
| OS=1, SR=0 | 到过但未正确停止 | STOP 判断、动作 chunk 过冲 |
| SR=1, SPL 低 | 成功但低效 | 绕路、重复转向、历史记忆干扰 |
| SR=1, SPL 高 | 高质量成功 | 可作为定性展示案例 |

为了让案例分析可复核，每个案例至少记录 `scene_id`、`episode_id`、原始指令、NE/OS/SR/SPL、步数和视频路径。少量成功/失败视频适合解释行为模式，不足以替代全量定量评测。
