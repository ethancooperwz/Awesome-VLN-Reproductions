# 环境配置

## 1. 推荐软硬件

官方测试环境为 Python 3.9、PyTorch 2.1.2、CUDA 12.4 和 Habitat-Sim/Lab 0.2.4。模型以 BF16 加载，建议使用支持 BF16 的 NVIDIA GPU；多 GPU 只负责把不同 episode 分发到不同进程，并不会把一个 7B 模型切分到多张卡上，所以每张卡都必须能独立容纳模型。

先确认驱动和基础工具：

```bash
nvidia-smi
conda --version
git --version
```

后续命令约定源码目录为：

```bash
export STREAMVLN_ROOT=/path/to/StreamVLN
```

请将其改为自己的绝对路径，不要直接照搬作者或本文原来的 `/home/...` 路径。

## 2. 创建 Conda 环境

```bash
conda create -n streamvln python=3.9 -y
conda activate streamvln

conda install -y \
  habitat-sim==0.2.4 \
  withbullet \
  headless \
  -c conda-forge \
  -c aihabitat
```

`headless` 适合服务器；如果需要本地图形窗口，应按 Habitat-Sim 官方说明选择对应构建，不要同时安装互相冲突的变体。

## 3. 安装 Habitat-Lab 0.2.4

```bash
git clone --branch v0.2.4 \
  https://github.com/facebookresearch/habitat-lab.git
cd habitat-lab
python -m pip install -e habitat-lab
python -m pip install -e habitat-baselines
```

安装后不要删除或移动这个源码目录，否则 editable install 会失效。

## 4. 安装 StreamVLN

```bash
git clone https://github.com/InternRobotics/StreamVLN.git "$STREAMVLN_ROOT"
cd "$STREAMVLN_ROOT"

python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

官方 `requirements.txt` 固定了 `torch==2.1.2`、`torchvision==0.16.2` 和 `transformers==4.45.1` 等版本。若环境里已有其他版本，先以 `pip check` 和下方自检结果为准，不建议随意升级 `transformers` 或 Habitat。

## 5. 安装 FlashAttention

预编译 wheel 必须同时匹配 Python、PyTorch、CUDA 和 C++ ABI。本文原环境使用的是：

```bash
python -m pip install \
  "https://github.com/Dao-AILab/flash-attention/releases/download/v2.7.0.post2/flash_attn-2.7.0.post2+cu12torch2.1cxx11abiFALSE-cp39-cp39-linux_x86_64.whl"
```

其中 `cp39` 对应 Python 3.9，`torch2.1` 对应 PyTorch 2.1。若你的组合不同，应从 FlashAttention release 选择匹配的 wheel 或按官方方式源码编译，不能只修改文件名。

## 6. 下载评测 checkpoint

```bash
cd "$STREAMVLN_ROOT"
python -m pip install "huggingface_hub[cli]==0.33.0"
mkdir -p checkpoints/StreamVLN-v1_3

huggingface-cli download \
  mengwei0427/StreamVLN_Video_qwen_1_5_r2r_rxr_envdrop_scalevln_v1_3 \
  --local-dir checkpoints/StreamVLN-v1_3
```

正常情况下完整仓库已经包含 tokenizer 文件。如果某次下载中断或这些文件缺失，可从旧 checkpoint 补齐 tokenizer：

```bash
huggingface-cli download \
  mengwei0427/StreamVLN_Video_qwen_1_5_r2r_rxr_envdrop_scalevln \
  added_tokens.json merges.txt special_tokens_map.json \
  tokenizer.json tokenizer_config.json vocab.json \
  --local-dir checkpoints/StreamVLN-v1_3
```

## 7. 环境自检

```bash
cd "$STREAMVLN_ROOT"

python - <<'PY'
import habitat
import habitat_sim
import flash_attn
import torch
import transformers

print("torch:", torch.__version__)
print("CUDA runtime:", torch.version.cuda)
print("CUDA available:", torch.cuda.is_available())
print("GPU count:", torch.cuda.device_count())
print("transformers:", transformers.__version__)
print("habitat import: OK")
print("habitat_sim import: OK")
print("flash_attn import: OK")
PY

python -m pip check
```

预期至少满足：CUDA 可用、能导入三个核心包、`torch` 为 2.1.2、`transformers` 为 4.45.1。`pip check` 若提示版本冲突，应先处理再下载数据和跑全量评测。

## 8. 版本留档

复现实验前记录版本，便于之后解释指标差异：

```bash
cd "$STREAMVLN_ROOT"
git rev-parse HEAD
conda env export --no-builds > streamvln-environment.yml
nvidia-smi > nvidia-smi.txt
```

官方曾修复过 `num_history` 未正确传入模型的问题；旧代码会显著影响性能，因此应记录 commit 并尽量使用最新评测代码。
